# 會議室租借系統

公司內部會議室預約網頁，不需 Exchange Server / Outlook，可直接放在 Linux 主機上使用。

## 功能

- 12 間會議室：南科二廠 101、102、201、202、301、302、501、502 會議室、5F 活動中心；南科五廠 1F 國際會議廳、202、302 會議室
- 依日期查看空閒時段，點時間表上的空閒格子即可預約
- 同一間會議室、同一時段重疊會自動擋下，並建議下一個空檔
- 支援搜尋、容納人數篩選、時間表 / 清單兩種檢視、取消預約
- 現代簡約風，支援響應式設計（RWD）

## 預約欄位

會議室、日期、會議名稱、開始 / 結束時間、預約人、備註。

## 多人同步

- 本機模式：同一瀏覽器多分頁會即時同步。
- 跨裝置同步（選用）：填入 Firebase Realtime Database 設定（見 `index.html` 內的 `FIREBASE_CONFIG` 說明）即可讓不同電腦看到同一份預約表。

## 使用方式

直接用瀏覽器開啟 `index.html`，或放到 Linux 主機的網站目錄，例如：

```bash
sudo cp index.html /var/www/html/
```

## 檔案

本專案只有一個主要檔案：`index.html`（HTML、CSS、JavaScript 全部整合在內）。
