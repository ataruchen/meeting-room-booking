給 IT / 管理者：如何讓全公司跨裝置同步（約 5 分鐘，一次性）

這個頁面本身不需要後端。如果只在同一台電腦或同一個瀏覽器使用，現在就能多人分頁同步。如果要讓不同電腦、不同部門即時看到同一份預約表，請用 Firebase Realtime Database：

  1. 到 Firebase Console 建立專案，啟用 Realtime Database（地區選 asia-southeast1 較近）。
  2. 建立 Web App，把取得的 firebaseConfig 貼到本檔案最下方 FIREBASE_CONFIG，取代 null。
  3. 依公司政策設定 Rules，內部測試可用 meeting-bookings 讀寫開放，正式上線建議再收緊。
  4. 把這個檔案放到 Linux 主機（Nginx / Apache 的網站目錄）即可，全公司用同一個網址開啟。

未填設定時，頁面會顯示「本機模式」，資料只存在這台裝置的瀏覽器，不會上傳到任何伺服器。

純前端單一檔案 ・ 可直接部署於 Linux 主機 ・ 不依賴 Exchange Server 或 Outlook
